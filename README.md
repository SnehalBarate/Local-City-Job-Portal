Local City Job Portal
A PHP & MySQL web application designed for local job searching and recruitment.

🌟 Key Features
Job Posting & Search: Employers can post vacancies, and seekers can filter jobs by city.
User Management: Secure registration and login for all users.
Admin Reporting: View all site activity in a centralized report.
Excel Export: Download user and job data directly into .xls files for offline use.
Responsive Design: Clean layout built with Bootstrap and custom CSS.

🛠️ Tech Stack
Language: PHP
Database: MySQL
Frontend: HTML, CSS, Bootstrap
Server: XAMPP

📂 Installation
Move the project folder to C:\xampp\htdocs\.
Import the .sql file from the /Database_File folder into phpMyAdmin.
Start Apache and MySQL in your XAMPP Control Panel.
Open your browser and go to http://localhost/Local_city_job/
